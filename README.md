# Decision Support Tool for Emergency Rooms

> This project implements process/queue mining techniques to analyze and predict ER wait times. It features a user-friendly dashboard to visualize parameter changes. 

---

## Overview
- Created for use by a triage lead, allowing analytics to predict which patients are likely to be admitted vs. discharged.
- Inputs: Patient encounter event log from arrival to discharge.

---

### load_data.py 

Load user's data. Saves user-assigned labels for case_id, activity, timestamp, resources, and attributes in data.
